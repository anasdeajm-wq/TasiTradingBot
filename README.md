# نظام تداول آلي للسوق السعودي (تداول)

بوت يجلب أسعار خمسة أسهم من السوق السعودي كل دقيقة، يحسب المؤشرات الفنية،
يطبق استراتيجية دخول وخروج، يدير المخاطر، ويرسل التنبيهات عبر تيليجرام.

## الملفات

| الملف | الوظيفة |
|---|---|
| `main.py` | جلب الأسعار من Twelve Data كل دقيقة + التخزين في SQLite + تشغيل المنظومة |
| `indicators.py` | MA20 / MA50 / MA200 / RSI / MACD / Volume Ratio |
| `strategy.py` | شروط الشراء والبيع (الهدف الأول +2% والهدف الثاني +4%) |
| `risk_manager.py` | مخاطرة 1% لكل صفقة، حد يومي 3%، حد أسبوعي 6% |
| `telegram_notifier.py` | تنبيه عند كل إشارة شراء أو بيع |

## الأسهم المتابَعة

| الرمز | الشركة |
|---|---|
| 2222.SR | أرامكو السعودية |
| 1120.SR | مصرف الراجحي |
| 2010.SR | سابك |
| 4001.SR | أسواق عبدالله العثيم |
| 4180.SR | فتيحي القابضة |

> **ملاحظة مهمة عن الرموز:** واجهة Twelve Data تستخدم الرمز الرقمي المجرد مع
> `mic_code=XSAU` (أي `2222` وليس `2222.SR`). التحويل يتم تلقائياً في
> `to_api_symbol()` داخل `main.py`، فتبقى الرموز معروضة بصيغة `.SR`.

## الإعداد

```bash
pip install -r requirements.txt

export TWELVE_DATA_API_KEY="مفتاحك من twelvedata.com"
export TELEGRAM_BOT_TOKEN="توكن البوت من BotFather"
export TELEGRAM_CHAT_ID="معرّف المحادثة"
```

الباقة المجانية في Twelve Data **لا تشمل سوق تداول**. أسهم السوق السعودي
تتطلب اشتراكاً يغطي بورصة Tadawul (XSAU)، وإلا سيرجع الخادم الخطأ 401.

## التشغيل

```bash
python main.py --backfill    # تحميل التاريخ اليومي أولاً (مطلوب لحساب MA200)
python main.py --once        # جولة واحدة: اجلب الأسعار واعرض النتائج
python main.py --loop        # التشغيل المستمر كل دقيقة أثناء جلسة السوق
python main.py --status      # حالة المخاطر والصفقات المفتوحة
python main.py --self-test   # اختبار المنظومة ببيانات تجريبية بدون شبكة
```

خيارات إضافية: `--db` لمسار قاعدة البيانات، `--capital` لرأس المال،
`--interval` للفاصل الزمني، `--ignore-market-hours` لتجاهل أوقات الجلسة،
و`--live` لتسجيل الصفقات فعلياً (الوضع الافتراضي محاكاة).

## الاستراتيجية

**شروط الشراء** (يجب تحققها كلها):
1. السعر أعلى من MA50
2. الحجم أكبر من 1.5 ضعف متوسط الشموع السابقة
3. RSI أقل من 70

**شروط البيع:**
- الهدف الأول `+2%` → بيع 50% من الكمية
- الهدف الثاني `+4%` → بيع الكمية المتبقية
- وقف الخسارة يُفحص قبل الأهداف

## إدارة المخاطر

| البند | القيمة |
|---|---|
| رأس المال | 100,000 ريال |
| المخاطرة لكل صفقة | 1% = 1,000 ريال |
| حد الخسارة اليومي | 3% = 3,000 ريال |
| حد الخسارة الأسبوعي | 6% = 6,000 ريال |
| وقف الخسارة الافتراضي | 2% تحت سعر الدخول |
| أقصى قيمة لصفقة واحدة | 20% من رأس المال |

حجم الصفقة = (رأس المال × 1%) ÷ (سعر الدخول − وقف الخسارة)، ثم يُقيَّد
بسقف 20% من رأس المال. الأسبوع في `risk_manager` يبدأ يوم **الأحد** ليطابق
أسبوع تداول (الأحد إلى الخميس).

عند بلوغ الحد اليومي أو الأسبوعي يتوقف فتح أي صفقة جديدة ويُرسَل تنبيه.

## قاعدة البيانات

SQLite بخمسة جداول: `prices` (الشموع)، `quotes` (اللقطات اللحظية)،
`indicators` (المؤشرات المحسوبة)، `signals` (الإشارات)، `trades` (الصفقات).

## تنبيه

النظام للأغراض التعليمية والبحثية. الوضع الافتراضي هو المحاكاة ولا ينفّذ
أوامر لدى أي وسيط. التداول ينطوي على مخاطر خسارة رأس المال.
