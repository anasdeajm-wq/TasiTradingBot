# نظام تحليل ومضاربة السوق السعودي (تداول)

نظام يدرس أسهم السوق السعودي، يقيس أداء أنماط الدخول قياساً فعلياً، يدير
المخاطر، ويتعلّم من أخطاء توقعاته.

## المبدأ الحاكم

**لا رقم في هذا النظام مبني على رأي.** كل نسبة ومعامل إما مقيس من بيانات
تاريخية أو معلَّم صراحة بأنه غير معاير. الفرق بين الاثنين ظاهر في كل
تقرير، لأن رقماً مخموناً يُعرض كأنه مدروس هو أخطر ما في أي نظام تداول.

## التشغيل

```bash
pip install -r requirements.txt

python -m tasi.cli db-status
python -m tasi.cli universe-import companies.csv
python -m tasi.cli shariah-import osaimi.csv \
    --source "مركز المقاصد - العصيمي" --as-of 2026-07-01
python -m tasi.cli tradable --allow PURE MIXED
python -m tasi.cli backtest --benchmark TASI --save
python -m tasi.cli regime --benchmark TASI --save
python -m tasi.cli briefing
python -m tasi.cli viability --capital 300
```

## التصنيف الشرعي

**النظام لا يصدر حكماً شرعياً أبداً.** الحالة الافتراضية لأي سهم
`UNVERIFIED`، والسهم غير المصنَّف مستبعد من التداول تلقائياً. التصنيف
يُستورد من مصدر تختاره أنت، ويُخزَّن باسم مصدره وتاريخ سريانه لأن القوائم
تتغيّر كل ربع سنة وتختلف الجهات على السهم الواحد.

المصدر الرسمي لمعيار العصيمي هو **مركز المقاصد**. راجع `templates/README.md`.

## ضمانات الصدق في القياس

هذه القيود مطبّقة في `backtest.py`، وكل واحدة منها تمنع نتيجة متفائلة كاذبة:

1. الدخول عند افتتاح الشمعة **التالية** للإشارة، لا عند إغلاق شمعة الإشارة.
2. وقف الخسارة يُفحص على أدنى الشمعة قبل الهدف على أعلاها.
3. الشمعة التي تلامس الوقف والهدف معاً تُحتسب وقف خسارة.
4. النتيجة بوحدات المخاطرة (R) لتكون الأسهم مختلفة التقلب قابلة للمقارنة.
5. العمولة والانزلاق مخصومان من كل صفقة.
6. النمط الذي توقعه الرياضي سالب أو صفقاته أقل من 20 يأخذ وزناً صفراً.

**اختبار التحقق**: تشغيل النظام على سلاسل شبه عشوائية يعطي توقعاً سالباً.
هذه هي النتيجة الصحيحة. نظام يبدو رابحاً على بيانات عشوائية دليل على
تسرّب من المستقبل لا على وجود أفضلية.

## التعلّم من الخطأ

كل توقع يُسجَّل **قبل** معرفة النتيجة مع كامل خصائصه وحالة السوق. عند
حلول أجله يُقيَّم، وعند الخطأ يُصنَّف السبب: صدمة خبرية، تغيّر حالة سوق،
سيولة ضعيفة، ثقة زائدة، أو انحياز نموذج. الأسباب الخارجية تُفحص قبل إلقاء
اللوم على النموذج، وإلا بدا كل خطأ خطأ نموذج فلا يتحسّن شيء.

يُقاس أيضاً **معايرة الثقة** بمقياس Brier: حين يقول النظام ثقة 70% هل
يصيب فعلاً في 70% من الحالات؟ نظام واثق أكثر مما يستحق أخطر من نظام قليل
الإصابة يعرف قدره.

## الحالة الراهنة

- الأنماط الخمسة **غير معايرة**. معاملاتها الحالية قيم ابتدائية لتشغيل
  القياس، وتصبح مقيسة بعد `backtest --save` على بيانات حقيقية.
- مصدر البيانات لم يُختر بعد. طبقة المزوّدين جاهزة، ومزوّد إعادة التشغيل
  يسمح ببناء واختبار كل شيء بلا اشتراك.
- التنفيذ الآلي غير متاح لحسابات الأفراد لدى الوسطاء السعوديين، فالنظام
  يقترح الأوامر والمستخدم ينفّذها.

## تنبيه

للأغراض البحثية والتعليمية. النظام لا ينفّذ أوامر لدى أي وسيط. التداول
ينطوي على مخاطر خسارة رأس المال، ولا يوجد نظام يضمن ربحاً.
